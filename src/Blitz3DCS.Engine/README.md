# Blitz3DCS.Engine

This project contains a managed scene graph and transform layer for the modern engine path. It has no dependency on the legacy runtime or Direct3D 7. Its transform conventions follow the behavior of Blitz3D 1.118, including column-basis affine composition, Euler conversion order, one-based child enumeration, and world-preserving parenting by default.

The scene and transform behavior is based on the Blitz3D open-source release by Blitz Research Ltd. The original release is available at <https://github.com/blitz-research/blitz3d> and is distributed under the zlib/libpng license. This project is a separately implemented managed adaptation, not the original Blitz3D source.
